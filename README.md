# 假手机 · 礼物网页（可个性化定制）

一个伪装成 iPhone 的沉浸式小网站：锁屏 → 主屏 → 聊天 / 相册 / 音乐 / 备忘录 / 日历 / 邮件 / 电话 /
Instagram / Twitter / Facebook / 设置。
界面是 **iOS 4 拟物风格**（水滴壁纸、玻璃质感图标、居中时间 + 3G 状态栏），**全英文**。

现在可以直接在网页里改内容：换名字、头像、壁纸、照片、音乐、联系人、聊天台词、备忘录、日历、邮件、
社交动态……不需要改代码。

- **一键自定义**：右下角（手机上在右上角）的「✎ 自定义」按钮，打开右侧编辑面板。
- 修改先放在当前浏览器里；点「保存并应用」立即生效。
- **一键分享**：在「备份/重置」里点 **生成分享网页 (.html)**，得到一个独立的 `index.html`
  （图片、音乐全部内嵌），对方打开就能玩；或者 **生成分享压缩包 (.zip)** 拖到 Netlify Drop /
  Cloudflare Pages，直接换成一个网址。分享页没有编辑按钮，内容固定在生成那一刻。
- **云端作品**：修改会自动保存到 Supabase；点「分享我的作品」直接生成只读链接（`?p=...`）。
  别人打开只能看，不能改；你更新内容后再点一次分享即可。
- 也支持完整备份（含上传的图片和音乐）导入到另一台电脑继续编辑。

## 怎么打开

- **本机预览**：双击 `index.html`（推荐 Chrome / Edge）。
- **手机上**：把整个文件夹放到静态托管（见文末），用手机浏览器打开。

| 相册 | 按月份分组，批量上传照片、写说明、排序 |
| 音乐 | 歌曲名、歌手、封面、上传音频，排序 |
| 备忘录 | 标题、日期、正文 |
| 日历 | 日期、时间、标题、地点 |
| 邮件 | 发件人、主题、日期、正文、未读红点 |
| 通话 | 联系人、类型（来电/拨出/未接）、时间、时长 |

### 保存与分享

修改都保存在当前浏览器的本地存储里（文字在 localStorage，图片/音乐在 IndexedDB）。

- **保存并应用**：写入浏览器并刷新页面。保存后会直接回到主屏（不必再输密码）。
- **生成分享网页 (.html)**：把**已保存**的全部内容（包括上传的图片、音乐，以 base64 内嵌）打包成
  一个独立的 `index.html`。这个文件不依赖 `assets/` 或任何其它文件，双击就能看；也可以直接上传到
  静态托管。分享页不含编辑按钮，内容固定在生成那一刻。
- **生成分享压缩包 (.zip)**：同样的内容装进 `idol-phone-share.zip`（内部是一个 `index.html`），
  方便直接拖到 Netlify Drop / Cloudflare Pages 换网址。
- **导出成品 data.js**：只想替换数据、保留整个文件夹时用。把新的 `data.js` 覆盖原文件即可。
- **导出完整备份 (.json)**：用于换电脑/换浏览器继续编辑，之后可用「导入备份」恢复。
- **仅导出文字内容**：文件很小，但换电脑后上传的素材会丢失（引用的素材会显示不出来）。
- **恢复默认内容**：清除所有自定义、上传素材、密码和备忘录修改，回到初始演示。

> ⚠️ 分享网页是在**点击按钮那一刻**把内容固化的。改完内容要先「保存并应用」，再生成分享网页；
> 之后又改了内容，需要重新生成/重新上传。
>
> ⚠️ 分享页仍然是公开网页（拿到网址的人都能看）。不要放真实姓名、真实私人照片或真实聊天记录。

#### 拿到一个可以发给对方的网址

**Netlify Drop（最快，不需要装东西）**

1. 定制面板 →「备份/重置」→ **生成分享压缩包 (.zip)**；
2. 打开 <https://app.netlify.com/drop>，把 `idol-phone-share.zip` 拖进去；
3. 等十几秒，得到一个 `https://xxx.netlify.app` 网址，发给对方即可
   （免费注册/登录后站点才会长期保留）；
4. 以后更新：重新生成 zip，在站点的 **Deploys** 页再把 zip 拖进去覆盖。

**Cloudflare Pages**：登录 <https://pages.cloudflare.com> → Create → Pages → Upload assets，
上传同一个 zip，得到 `xxx.pages.dev`。

> 直接把 `index.html` 文件发给对方也能打开，但微信/QQ 里的 HTML 附件在手机上不一定能正常预览，
> 所以更推荐发网址。发文件时建议先自己双击确认一下效果。

### 云端作品与分享（Supabase）

线上版还接入了 Supabase，每个访问者都可以拥有自己的云端作品：

- 编辑时约 1–2 秒自动保存到云端，编辑器顶部显示「保存中… / 已保存到云端 / 保存失败」。
- 第一次自动保存会自动创建一个**匿名云端作品**（同一浏览器最多 3 个）。
- 「备份/重置」→「云端作品 / 分享」→ **分享我的作品**，会生成一个只读链接：
  `https://wardoooooo.github.io/idol-phone/?p=<作品ID>`。
- 分享的是点击那一刻的**冻结快照**；之后改了内容，要再点一次「分享我的作品」才会更新。
- 别人打开分享链接只能看，没有编辑按钮；他自己的笔记/密码修改只存在他自己的浏览器。
- 图片/音乐上传到 Supabase Storage：单文件 ≤ 10MB，每个作品素材总量建议 ≤ 20MB，文字配置 ≤ 1MB。

限制与注意：

- 匿名作品绑定当前浏览器；清缓存、换设备或换浏览器会失去**编辑入口**（已经发布出去的只读链接仍然有效）。
  重要内容请用「导出完整备份」保存。
- Supabase 免费项目长期没有访问可能会被暂停，需要登录 Supabase 控制台恢复。
- 分享链接和上传的素材都是公开可访问的；不要放真实姓名、真实私人照片或真实聊天记录。
- 目前没有内容审核；如果要公开推广，建议后续加举报/删除和管理员清理。

技术文件：

- `cloud-config.js`：Supabase Project URL + publishable key（公开，受 RLS 保护；**不要**放 service_role key）。
- `cloud.js`：轻量客户端（匿名会话、自动保存、Storage 上传、发布/读取分享）。
- `supabase/schema.sql`：数据库表、RLS、项目和素材限制、Storage 桶与策略。
  换 Supabase 项目时，在 SQL Editor 里重新执行一遍。

### 关于素材

- 图片会自动缩小到最长边 1600px；大于 700 KB 的图片会转成 JPEG，节省空间。
- 音乐/语音不压缩，直接存进浏览器（IndexedDB）。浏览器一般有几百 MB 以上可用空间。
- 支持浏览器能播放的格式：MP3 / M4A / WAV / OGG 等。
- 如果「上传」没反应或提示失败，请换 Chrome / Edge，并确认不是无痕模式。

## 目录

```
idol-phone/
├─ index.html      页面外壳
├─ styles.css      手机界面样式
├─ app.js          引擎（一般不用改）
├─ icons.js        iOS 4 风格图标（SVG 手绘）
├─ data.js         ★ 默认内容（也可以直接手改）
├─ custom.js       自定义内容 / 素材存储 / 启动入口
├─ editor.js       网页内的定制面板
├─ editor.css      定制面板样式
├─ cloud-config.js Supabase URL + publishable key（公开）
├─ cloud.js        云端自动保存 / 分享 / 素材上传
├─ supabase/
│  └─ schema.sql   数据库、RLS、Storage 规则
├─ share-template.js  分享页模板（自动生成，不用手改）
├─ tools/
│  └─ build-share-template.js  重新生成分享模板
├─ README.md
└─ assets/         默认照片、头像、封面、音频
```

> `custom.js` 负责先读取浏览器里保存的定制内容、解析上传素材，再加载 `app.js` 启动手机。
> 所以不要再把 `app.js` 直接写回 `index.html`，否则定制内容不会生效。
>
> `share-template.js` 把页面外壳、样式、图标和引擎打包在一起，并内嵌默认素材，这样即使
> `index.html` 是用 `file://` 直接打开的，也能生成完全独立的分享页。**改动 `index.html`、
> `styles.css`、`app.js`、`icons.js` 或 `assets/` 之后，记得重新运行：**
>
> ```bash
> node tools/build-share-template.js
> ```
>
> 否则生成的分享页仍会使用旧版本。

## 直接改 data.js（进阶）

`data.js` 里的字段和以前一样：

| 字段 | 说明 |
|---|---|
| `owner` | 手机主人：名字、英文名、头像、简介 |
| `theme` | 主题色（`accent` 主色、`accent2` 强调色） |
| `lock` | 锁屏密码（默认 0309，留空 = 点击解锁）、锁屏壁纸、锁屏通知 |
| `wallpaper` | 主屏壁纸 |
| `weather` | 主屏天气小组件 |
| `contacts` | 联系人：`{ id: {name, avatar, status} }` |
| `chats` | 聊天记录：`{ 联系人id: [消息...] }` |
| `liveScript` | 你每发一条消息，对方依次回一条的台词 |
| `call` | 来电：谁打来、发到第几条消息时触发 |
| `photos` | 相册，按月份分组 |
| `songs` | 音乐列表（标题、歌手、封面、音频） |
| `notes` | 备忘录 |
| `events` | 日历事件（日期 YYYY-MM-DD） |
| `mails` | 邮件 |
| `calls` | 通话记录（`missed` 且 `seen:false` 会显示红点） |
| `social` | Instagram / Twitter / Facebook 的内容 |

### 消息格式

```js
{ t: 'date', text: 'Oct 18' }             // 日期分隔
{ t: 'them', text: '对方说的话' }          // 对方（左边）
{ t: 'me',   text: '主角说的话' }          // 主角（右边）
{ t: 'them', voice: '0:03', src: 'assets/voice_1.wav' }  // 语音条
```

### 手动替换素材

把文件放进 `assets/`，然后在 `data.js` 里改成对应文件名：

- 照片：`jpg/png`，建议 3:4 或 1:1；
- 音频：`mp3/wav`，语音 2–10 秒，歌曲 20–40 秒即可（只是氛围）；
- 头像：正方形，建议 400×400。

## 手机里的功能

- 主屏两页：左右滑动（或点底部圆点）切换；第二页放 Twitter / Facebook / Clock / Calculator /
  Weather / Settings，以及 Photos、Upcoming 小组件。
- 三个社交 App 是 **2011 年界面**：Twitter 旧网页、Facebook 经典蓝顶栏、Instagram 深蓝脚本 logo。
- **Clock**：世界时钟、闹钟开关、秒表、倒计时。**Calculator**：四则运算。**Weather**：当前 + 5 天预报。
- **Notes 可编辑**：列表右上角 ＋ 新建；打开笔记后右上角 Edit 修改。保存后存在浏览器里。
- 锁屏密码默认 **0309**，可在 Settings → Change Passcode 修改，也可以在定制面板里改。
- 打开 Mail / Phone 会清掉对应红色角标；打开会话会清掉该会话未读。
- Phone 右上角可切到拨号键盘；Messages 右上角 ✎ 可以新建短信。
- Settings 可开关飞行模式（状态栏 ✈）、Wi-Fi/蓝牙、勿扰、锁屏通知，调亮度，换壁纸，查看 About。

## 调试参数

在网址后面加：

- `?view=home` / `chat` / `photos` / `music` / `notes` / `calendar` / `mail` / `phone` / `about` / `call` —— 直接打开某一屏
- `?chat=list` —— 打开聊天列表而不是某个对话
- `&static=1` —— 关闭所有动画（截图用）
- `?test=1` —— 自动测试「发 3 条 → 回复 → 来电」
- `?debug=1` —— 把布局信息写进页面标题

## 部署（发一个网址给对方）

推荐用上面的「生成分享压缩包 (.zip)」→ 拖到 Netlify Drop / Cloudflare Pages，几步就能得到网址。
那里生成的分享页是**只读**的，对方看不到编辑按钮。

如果想把整个可编辑的文件夹都发给对方（对方也能继续改），才需要：

1. 定制面板 →「导出成品 data.js」，替换文件夹里的 `data.js`；
2. 把整个 `idol-phone` 文件夹压缩发送，或把文件夹拖到 Cloudflare Pages / Netlify。

> 公开网址不要把真实的私人照片、真实姓名、聊天记录放上去。

## 注意

- 这是原创实现，参考了同类“偶像手机”网页的玩法，但没有使用任何他人的代码、照片或音乐素材。
- 演示素材是程序生成的渐变图与提示音，替换成你自己的即可。
- 定制内容只存在当前浏览器；换浏览器、换电脑、清缓存都会丢失，重要内容记得导出备份。
